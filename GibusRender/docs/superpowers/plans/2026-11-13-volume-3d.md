# Volume 3D di posizionamento Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Disegnare sulla foto un volume 3D in prospettiva, con misure reali, attacco a muro e montanti, e usarlo come riferimento unico di posizione per il modello di immagini, la maschera e il controllo del risultato.

**Architecture:** Un modulo puro di geometria (`volume.ts`) ricava la posa della camera da un rettangolo noto della facciata (omografia) e proietta il volume; lo usano sia l'editor SVG nel browser sia il server. Il server salva il volume in una colonna JSON, ne deriva la sagoma (colonna `polygon` esistente, così maschera e ricomposizione restano invariate), disegna un'immagine-guida per il fornitore, estende il prompt e misura lo scostamento del risultato dal volume.

**Tech Stack:** Next.js 16.2.11, React 19.2.4, TypeScript 5, Prisma 7 (PostgreSQL), sharp 0.35, zod 4, Vitest 4. Nessuna nuova dipendenza.

**Spec:** `GibusRender/docs/superpowers/specs/2026-11-13-volume-3d-design.md`

## Global Constraints

- Tutto dentro `GibusRender/`. Prima di scrivere codice Next.js leggere la guida pertinente in `node_modules/next/dist/docs/` (`AGENTS.md`).
- Interfaccia, errori e commenti in italiano; prompt per il modello in inglese.
- `src/lib/render/volume.ts` è puro: niente Prisma, sharp, React, `@/lib/db`.
- Coordinate sulla foto normalizzate 0..1 (`Point` di `geometry.ts`); misure in mm interi; le maniglie arrotondano ai 10 mm.
- Colori del volume, ovunque: attacco a muro `#ff3b30`, montanti `#2f7bff`, spigoli bianchi tratteggiati.
- Focale predefinita: rapporto `f / diagonale = 0.60`; intervallo ammesso (stima e cursore) `0.30 … 2.50`.
- Montanti: da 0 a 6 sul fronte; sul retro solo per `AUTOPORTANTE`.
- I render senza volume e la sagoma a mano devono funzionare come prima: tutti i test esistenti restano verdi (`npm test`), `npm run lint` e `npx tsc --noEmit` puliti.
- Commit piccoli, messaggi nello stile del repository: `feat(gibus-render): …`, con la riga `Co-Authored-By` della sessione.

## Review Focus

1. **Riquadro quasi frontale** (lati opposti paralleli): la focale non è ricavabile; ci si aspetta la focale predefinita e un volume comunque sensato, non NaN. Test in Task 1.
2. **Riquadro cliccato in ordine diverso o degenere** (punti allineati, incrociati, minuscolo): errore italiano, mai un volume esploso. Test in Task 1.
3. **Volume che esce dalla foto**: la sagoma derivata viene ritagliata a 0..1 e resta valida; se è tutta fuori, errore. Test in Task 2.
4. **Render vecchi (colonna `volume` null) e duplicazione** di un render con volume: pagina del render, bozza e generazione non devono rompersi. Test in Task 2 e Task 5.
5. **Modelli con tetto di immagini o che non accettano la guida** (FLUX Kontext, Klein a 10): la guida non fa superare il tetto e non arriva a Kontext. Test in Task 4.

```ts
export type Vec3 = [number, number, number];
/** Angoli nell'ordine: basso-sx, basso-dx, alto-dx, alto-sx. */
export type RefRect = { corners: [Point, Point, Point, Point]; widthMm: number; heightMm: number; baseMm: number };
export type VolumeBox = { offsetXMm: number; distanceMm: number; wallHeightMm: number; frontHeightMm: number };
export type Volume = {
  ref: RefRect;
  focalRatio: number | null;          // null = automatica
  box: VolumeBox;
  frontPosts: number[];               // frazioni 0..1 lungo la larghezza
  rearPosts: number[];
  nudges: Point[] | null;             // 8 scostamenti 0..1, ordine dei vertici
};
export type VolumeDims = { widthMm: number; depthMm: number };
export type Pose = { f: number; R: number[][]; t: Vec3; width: number; height: number };
export type Post = { foot: Point; head: Point; xMm: number; rear: boolean };
export type ProjectedVolume = {
  pose: Pose;
  focalRatio: number;                 // quella effettivamente usata
  focalAuto: boolean;                 // true se ricavata dal riquadro (non predefinita né manuale)
  /** 0-3 a terra (muro-sx, muro-dx, fronte-dx, fronte-sx), 4-7 in alto nello stesso ordine. */
  vertices: Point[];
  posts: Post[];
  wallLine: [Point, Point] | null;    // null se distanceMm > 0
  outOfFrame: boolean;
};
export const DEFAULT_FOCAL_RATIO = 0.6;
export const FOCAL_RATIO_MIN = 0.3;
export const FOCAL_RATIO_MAX = 2.5;
export const MAX_POSTS = 6;

export function orderCorners(pts: Point[]): [Point, Point, Point, Point];           // 4 clic in qualsiasi ordine → BL,BR,TR,TL
export function solvePose(ref: RefRect, photoW: number, photoH: number, focalRatio: number | null):
  { ok: true; pose: Pose; focalRatio: number; focalAuto: boolean } | { ok: false; error: string };
export function project(pose: Pose, p: Vec3): Point | null;                         // null dietro la camera
export function boxVertices(box: VolumeBox, dims: VolumeDims): Vec3[];              // 8 vertici in mm
export function projectVolume(v: Volume, dims: VolumeDims, photoW: number, photoH: number):
  ({ ok: true } & ProjectedVolume) | { ok: false; error: string };
export function volumeOutline(pv: ProjectedVolume): Point[];                        // involucro convesso di vertici e montanti, ritagliato a 0..1
export function alongAxis(pose: Pose, origin: Vec3, axis: Vec3, pointer: Point): number; // mm lungo la retta mondo più vicina al puntatore
export function defaultVolume(ref: RefRect, dims: VolumeDims, totalHeightMm: number, freestanding: boolean): Volume;
export function evenPosts(count: number): number[];                                 // 0→[], 1→[0.5], n→equidistanti da 0 a 1
export const roundMm = (v: number) => Math.round(v / 10) * 10;
```

Convenzioni: mondo in mm, origine sotto l'angolo basso-sx del riquadro alla quota terra (gli angoli del riquadro sono `(0,base,0) (w,base,0) (w,base+h,0) (0,base+h,0)`), X lungo il muro a destra, Y in alto, Z fuori dal muro verso la camera. Camera: x a destra, y in basso, z in avanti, punto principale al centro, `f` in pixel. Messaggi d'errore: `"Il riquadro di facciata non è valido: clicca i quattro angoli di un rettangolo"`, `"Il riquadro di facciata è troppo piccolo"` (lato minore < 5% del lato corto della foto), `"Il volume finisce dietro la fotocamera: riduci la sporgenza o regola la prospettiva"`.
